# Fotofolio Martha Aisyah Putri

Website 4 halaman: `index.html` (Beranda), `tentang.html`, `sekolah.html`, `galeri.html`.

## Ganti isi
Semua teks ada di bagian atas `script.js` (`PROFIL`, `SEKOLAH`, `GALERI`). Kolom kosong tidak ditampilkan.

## Tambah foto galeri
Taruh file di folder `foto/`, lalu tambah satu baris di `GALERI`:
`{src:"foto/foto-2.jpg",judul:"Judul foto"}`

## Deploy (GitHub Pages)
Upload semua isi folder ke repo Public, lalu Settings > Pages > Deploy from a branch > `main` / root.
