# Fotofolio Martha Aisyah Putri

Website fotofolio dan riwayat sekolah (HTML, CSS, JavaScript).

## Struktur

```
fotofolio-martha/
├── index.html
├── style.css
├── script.js
├── README.md
└── foto/
    └── foto-1.jpg
```

## Ganti isi

Buka `script.js`, edit bagian paling atas:

- `PROFIL`: nama, bio, foto utama, dan data diri (kolom kosong tidak ditampilkan)
- `SEKOLAH`: nama sekolah, ikon, tahun, dan keterangan

## Ganti foto

Upload foto baru ke folder `foto/` dengan nama `foto-1.jpg` (menimpa yang lama). Kalau memakai nama lain, ubah `fotoUtama` di `script.js`. Pakai foto persegi supaya pas di lingkaran.

## Deploy dengan GitHub Pages

1. Buat repo baru di github.com (Public), upload semua isi folder ini.
2. Buka **Settings** lalu **Pages**.
3. Source: **Deploy from a branch**, Branch: `main`, folder `/ (root)`, klik **Save**.
4. Tunggu 1 sampai 2 menit. Link: `https://USERNAME.github.io/NAMA-REPO/`
